# Code of Conduct

NeedWise follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussions about the
work. Harassment and personal attacks are not tolerated.

To report unacceptable behavior, contact the maintainers privately through GitHub (a direct
message to a maintainer, or the private reporting channel in [SECURITY.md](SECURITY.md) if you
prefer). Reports are handled confidentially.
