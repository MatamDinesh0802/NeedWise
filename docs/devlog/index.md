# Devlog

WorkMind is built in public, one phase at a time ([Roadmap](../ROADMAP.md)). Each milestone gets
a short post that shows something real: a diagram, a measured number, the app itself. These are
the drafts. None has been posted yet: they wait until the repository is public, because each one
links to it.

Every number in a post comes from a committed evaluation report, and every image is generated
from the code or the running app (the images and their HTML sources are in `docs/devlog/assets/`).
