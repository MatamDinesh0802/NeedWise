NeedWise · Build log #3

What happens between “upload PDF” and an AI answer

1

Read it

PDF, Word, Excel, PowerPoint, Markdown, HTML, CSV and Slack exports. Headings and page numbers are kept, so every answer can say where it came from.

2

Cut it by structure, not by character count

Chunks follow sections. Tables split by rows, with the header repeated in every piece, so a row never loses its column names.

3

Label what is sensitive

Look for data, not topics: a valid IBAN, an ID number, a salary next to an amount. A leave policy that mentions “medical” is not secret.

4

Embed it, locally

A 300M-parameter embedding model on the laptop GPU, plus keyword vectors for exact codes like “INC-2026-031”. Document text never leaves the machine to be indexed.

5

Attach the permissions to every chunk

Each chunk carries who may read it. Search filters on that list first; change the sharing and the index updates in the same request.

6

Swap versions without a gap

Same bytes: nothing happens. New bytes: the new chunks go live before the old ones are removed, so search never sees half a document.
